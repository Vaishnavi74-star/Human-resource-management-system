# 🚀 DAYFLOW

### Every workday, perfectly aligned.

DAYFLOW is a modern **HR Management System (HRMS)** that connects employees and HR teams through one centralized platform.

## 🎯 Problem

HR teams often use disconnected systems for:

- Employee management
- Attendance
- Leave
- Payroll
- Documents
- Notifications
- Reports

This leads to manual work, scattered data, and delayed HR operations.

## 💡 Solution

DAYFLOW brings all essential HR operations into **one simple, secure, and responsive platform**.

## ✨ Features

### 👤 Employee
- 🔐 Authentication
- 👤 Profile management
- ⏱️ Attendance & Check-in/Check-out
- 🏖️ Leave requests
- 💰 Salary & Payslips
- 📄 Documents
- 🔔 Notifications
- ⚙️ Settings

### 🧑‍💼 HR / Admin
- 📊 HR Dashboard
- 👥 Employee Management
- ⏱️ Attendance Monitoring
- 🏖️ Leave Approval
- 💰 Payroll Management
- 📄 Document Management
- 📈 Reports & Analytics
- 🔎 Global Search

## 🛠️ Tech Stack

**Frontend:** React, TypeScript, Vite, Tailwind CSS, React Router

**Backend:** Supabase, PostgreSQL, Supabase Auth, Storage, RLS

**Tools:** Git, GitHub, VS Code, npm


## 🏗️ Architecture

```text
React + TypeScript
        ↓
   Service Layer
        ↓
     Supabase
   ↙     ↓      ↘
 Auth  PostgreSQL  Storage
        ↓
       RLS
        ↓
 Employee / HR


## Security
Supabase Authentication
Role-based access
Protected routes
PostgreSQL Row Level Security (RLS)
Secure environment variables


## ⚙️ Run Locally
git clone <YOUR_REPOSITORY_URL>
cd dayflow
npm install
npm run dev

## Create .env:

VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
